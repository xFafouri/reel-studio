# Sound design and the mix

## The layers
1. **Voice**: the loudest, always clear. Takes at ≈ −18 LUFS each, boosted a little on the bus.
2. **Sound effects**: short accents on the picture's beats (`scripts/sfx.mjs`, 31 effects, generated by ffmpeg
   math: no licence questions). `node sfx.mjs list` / `node sfx.mjs all sfx/` to audition.
3. **Music bed**: about **−31 LUFS** under a voice (≈ −24 for music-only parts, e.g. a logo outro), ducked by the
   voice (sidechain, threshold 0.03, ratio 6, attack 20 ms, release 900 ms calm / 400 ms lively), 1 s fade-in, 2–3 s
   fade-out (a short fade can cut a loud accent into a click).
4. **Final**: `loudnorm=I=-14:TP=-1.5:LRA=11` → about −14 LUFS, peak ≤ −1.5 dBTP, AAC 160k 48 kHz stereo.
   Single-pass loudnorm lands within ~1 LU on Reels (−13.8 … −15.5 seen); accept it or run two-pass for exact.
`scripts/mix.mjs cues.json` does all four from one cue sheet.

## Which effect where
| Moment | Effect |
|---|---|
| Every scene change (not a cut) | `whoosh` 0.2 s before the change |
| Small thing appears (label, sticker, icon) | `pop` |
| A right answer, a key number lands | `ding` |
| Myth stamped / dramatic reveal | `stamp` + `sting` together, with a visual shake |
| "Wrong" | `buzz` |
| Time passing / countdown | `tick` |
| Before a reveal | `riser:<s>` ending exactly on the reveal frame |
| Title slam | `boom` |
| Relief / good ending | `pad:<s>` |
| Tension | `drone:<s>`, `heart` |
| Objects | `clink` (ice), `splash`, `bubbles`, `under:<s>`, `crack`, `gavel`, `bang`, `whir:<s>`, `vibe`, `rewind`, phone set (`ring`, `pickup`, `hangup`, `dial`, `ringback:<s>`), `glitch`, `scan`, `thud`/`tap` steps |
Don't stack more than two effects on one beat; leave the voice's first word clean.

## Making new effects
- ffmpeg `aevalsrc` = a formula of `t`: a pitch drop `sin(2*PI*(F0-k*t)*t)`, decay `exp(-a*t)`, noise
  `(random(0)*2-1)`, gates `between(t,a,b)`. `anoisesrc` for whooshes (pink, bandpass, fades).
- sox: `sox -n -r 48000 -c 1 out.wav synth 0.7 pluck C5 fade 0 0.7 0.6 gain -6` (plucks, sines, noise, flanger,
  phaser). Design each sound at the exact time of the animation beat it belongs to.
- Add new ones to the `SFX` table in `sfx.mjs` with a one-line comment (the comment is what `list` shows).

## Music
Free sources: Pixabay Music, YouTube Audio Library (check each track's licence; credit when asked). Pick by mood;
keep a few approved tracks in `assets/music/` with their credits. For a long video, loop with `-stream_loop -1`
and fade at the end. Ambience beds (rain, nature) from freesound.org CC0/CC-BY: keep a CREDITS file.

## Clip sound
A clip's own audio: cut with the same `-ss/-to`, `atempo` like its picture rate, `afade` 40 ms in / 120 ms out,
float WAV, mixed as an extra voice-bus line with its own gain.
